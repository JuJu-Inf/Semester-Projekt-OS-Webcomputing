# Semester-Projekt-OS-Webcomputing

Project-link: http://pan.th-brandenburg.de/~radkep/project.html

Project Description:

This website features a classic Snake arcade game with a simple three-page structure: a homepage, a gameplay page, and a results page.

On the homepage, players can enter their name and customize the color of their snake before starting the game. These details are later used on the scoreboard to identify each player's result.

The game page contains the Snake experience itself, implemented in an embedded frame. The objective is simple: guide the snake, collect food, and grow as long as possible to increase your score. The game ends if the snake collides with a wall or with its own body.

After the game ends, players can either restart and try to beat their previous score or continue to the scoreboard. The scoreboard displays all locally stored results, sorted by highest score first, along with the player information entered at the start.

For more information about the developers of this project, visit our About Us page linked in the footer on every page.
